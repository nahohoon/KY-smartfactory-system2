KY 재고·물류관리 시스템 — 사용설명서
========================================

1. 실행 방법
   - KY_재고물류관리_실행.html 파일을 더블클릭하세요.
   - Chrome 또는 Edge 브라우저에서 열립니다.
   - npm install · 빌드 · 서버 설치 불필요합니다.

2. 로그인
   - 아이디 : admin
   - 비밀번호 : ky1234
   - 추가 계정 : HTML 파일 상단 CONFIG.USERS 배열에 직접 추가하세요.

3. Google Sheets 연동 (선택사항)
   (1) Code.gs 파일 내용을 Google Apps Script 편집기에 붙여넣습니다.
   (2) 상단 메뉴 [배포] → [새 배포] → 유형 [웹 앱] →
       "다음 사용자로 실행: 본인" · "액세스 권한: 모든 사용자" 선택 후 [배포]
   (3) 배포된 URL을 복사합니다.
   (4) 시스템 설정 탭 → Apps Script URL에 붙여넣기 →
       저장 방식을 "Google Sheets 저장"으로 변경 → [설정 저장]
   (5) [연결 테스트] 버튼으로 정상 연결 확인
   (6) [품목 동기화] 또는 [이력 동기화] 버튼으로 데이터 가져오기

4. 주요 기능
   - 입출고 등록 : 품목명 자동완성 · 현재고 미리보기 · 마이너스 재고 방지
   - 재고 조회   : 창고별 현재고 · 부족재고 알림 (부족 재고 탭 빨간 배지)
   - 품목 마스터 : 품목 추가 / 수정 / 삭제 (Google Sheets 즉시 반영)
   - 통계        : 창고별 비율 · 출고 TOP 품목 · 월별 입출고 테이블
   - CSV 내보내기: 입출고 이력 · 재고 현황 각각 다운로드

5. 오프라인 사용
   - GAS URL 미설정 상태에서는 브라우저 localStorage에만 데이터가 저장됩니다.
   - 인터넷 연결 없이도 완전히 작동합니다.
   - 로그인 즉시 alert 창으로 성공 확인 → 화면 전환 순서로 동작합니다.

KY Smart Factory System
재고·물류관리 솔루션 백업 및 운영 저장소

중소 제조업 및 유통업체를 위한 스마트공장형 재고·물류관리 시스템입니다.

## 주요 기능

- 입고 / 출고 등록
- 실시간 재고 조회
- 부족재고 알림
- 품목 마스터 관리
- 입출고 이력 검색
- 기간 조회
- 엑셀 / CSV 다운로드
- 대시보드 통계

## 기술 스택

- Vite
- React
- TypeScript
- Tailwind CSS

## 목적

기초 스마트공장 구축, 내부 물류관리 효율화, 고객사 납품형 솔루션 운영
